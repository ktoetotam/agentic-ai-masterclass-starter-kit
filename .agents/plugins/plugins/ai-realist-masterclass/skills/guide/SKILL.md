# Guide

Work in the AI Realist masterclass starter project. Read `AGENTS.md` and `.agents/skills/masterclass-guide/SKILL.md` in the current project before acting, and load its reference files as that skill directs. Those project files are the detailed, maintained instructions; adapt skill names and commands to Codex or Claude Code as appropriate.

Participants are mostly non-technical: plain language, one question at a time, paste-ready next steps. The guide orients and plans; building belongs to the matching challenge skill.
