# AI Realist Agentic AI Masterclass

Read `AGENTS.md` before changing this project. Its source checks, Poetry dependency rules, `.env` handling, Git workflow and deployment boundaries apply here too. Read the relevant guide in `guides/` and the corresponding skill in `.agents/skills/` for the task at hand.

The optional Claude Code plugin in this repository exposes the same workshop topics as `/ai-realist-masterclass:setup`, `/ai-realist-masterclass:teamwork`, `/ai-realist-masterclass:build`, and the other plugin skills. References to `$masterclass-*`, Codex settings and ChatGPT Plus in the shared guides are specific to Codex. Claude Code access has its own sign-in and billing; do not assume ChatGPT Plus pays for it or for API usage.

For the first session, install the needed local tools, make a free GitHub account, then clone and open the public starter repository. Stop there. The facilitator will arrange group repositories later.
